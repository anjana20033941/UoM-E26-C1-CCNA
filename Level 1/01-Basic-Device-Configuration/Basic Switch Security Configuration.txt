Basic Switch Security Configuration 

This project demonstrates basic security configuration on a Cisco Catalyst 2960 Switch using Cisco Packet Tracer. 

Topology 

- 1 x Cisco 2960 Switch (`SW-Floor-1`) 
- 1 x PC (`PC0`) connected via Console Cable 


Commands Used & Configuration


Switch>enable
Switch#conf t
Enter configuration commands, one per line. End with CNTL/Z.
Switch(config)#hostname SW-Floor-1
SW-Floor-1(config)#line console 0
SW-Floor-1(config-line)#password cisco
SW-Floor-1(config-line)#login
SW-Floor-1(config-line)#exit
SW-Floor-1(config)#enable secret class
SW-Floor-1(config)#line vty 0 15
SW-Floor-1(config-line)#password cisco
SW-Floor-1(config-line)#login
SW-Floor-1(config-line)#exit
SW-Floor-1(config)#service password-encryption
SW-Floor-1(config)#banner motd # Access only Authorized person #
SW-Floor-1(config)#end
SW-Floor-1#disable
SW-Floor-1>
SW-Floor-1>exit

SW-Floor-1 con0 is now available

Press RETURN to get started.
