# 🌐 Cisco CCNA Level 1 - Learning & Lab Repository

Welcome to my **Cisco CCNA Level 1** repository! This project serves as a comprehensive documentation of my networking journey, practical CLI command logs, configurations, and Packet Tracer lab topologies completed during my CCNA studies.

---

## 📌 Topics Covered
- **Cisco IOS Command Modes & Navigation** (User EXEC, Privileged EXEC, Global Config, Subconfig)
- **Basic Switch & Router Initial Configuration** (Hostnames, Passwords, Banners)
- **Securing Management Access** (Console, VTY Lines, SSH Setup)
- **IP Addressing & Subnetting Basics** (IPv4 & IPv6 Fundamentals)
- **Interface Management & Network Verification** (`show` and `debug` commands)
